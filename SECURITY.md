# Security

If a catalog link now serves something harmful (malware, phishing, a swapped file), please
**open an issue with the entry id** or, for anything sensitive, use GitHub's
"Report a vulnerability" (Security tab). We remove the entry first and investigate after.

Defences already in place: maintainer review on every PR, file-signature and size checks
on every link every day, https-only links, no file lockers / shorteners / signed URLs, and
read-only CI for pull requests.
